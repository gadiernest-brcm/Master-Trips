איך להוסיף טיול חדש בעתיד?

הקובץ נבנה בצורה מודולרית ונקייה לחלוטין

כל טיול נשמר כ-Template מובנה בתחתית הקובץ:

  1. פתחו את הקובץ הנוכחי בעורך טקסט (כמו VS Code או Notepad).
  2. העתיקו את אחד מתגי ה-<template id="trip-template-NAME"> בתחתית והדביקו בתוכו את קוד ה-HTML של הטיול החדש.
  3. הוסיפו כפתור בסרגל העליון וכרטיס בדשבורד עם ה-ID של הטיול החדש.
  4. זה הכל! הטיול החדש יופיע מיד עם סינון, בידוד מלא וללא שום התנגשות קוד.
